Draußen regnete es Zahlen, aber nur ungerade, weil die geraden an dem Tag frei hatten und lieber Minigolf spielten.

Der Kühlschrank hingegen brummte zustimmend, was Reinhold als tiefe Weisheit deutete, obwohl es nur der Kompressor war, der wieder mal keine Lust hatte.
